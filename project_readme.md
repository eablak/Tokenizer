## Token Features

- **Name**: Wallet42 
- **Symbol**: WAL42

This token is designed for hypothetical use across all 42 campuses. It can use for shopping on intra instead of using intra wallet.

- **Blockchain**: Ethereum
- **Standard**: ERC-20

Token firstly determined for build on BEP-20 standards on [Binance (BNB) Smart Chain](https://www.bnbchain.org/en). After creation of wallet i can't get test tokens on [BNB Faucet](https://www.bnbchain.org/en/testnet-faucet) because it's needed at least 0.002 BNB as started. While i was try to get this initial BNB i found to send the Ethereum Sepolia to my wallet from [Google Faucet](https://cloud.google.com/application/web3/faucet). So, because of i get my initial free tokens from Ethereum i decide to continue with Ethereum blockchain with ERC-20 standards.

<b><i>NOTE</b>: BEP-20 token standards based on ERC-20 standards.</i>

- **Initial Supply**: 1000 WAL42
- **Decimals**: 18

Initial supply and decimal values are preferential, i chose simple and common values.

- **Supply Type**: Fixed Supply
- **Minting**: Only during contract deployment
- **Burnable**: No
- **Transferable**: Yes

To keep the token simple i make this decides.
